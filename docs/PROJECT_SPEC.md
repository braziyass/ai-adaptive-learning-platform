# AI Adaptive Learning Platform

## Goal

Develop a web application for one private school.

The application transforms PDF courses into interactive learning content using AI.

The generated content includes:

- Lessons
- Quizzes
- Placement Tests
- Validation Tests

Students learn progressively through levels.

Teachers monitor student progress.

Administrators manage students and teachers.

Only the developer manages PDFs.

Teachers never upload PDFs.

The frontend is web only.

Backend:

- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT

Frontend

- React
- TypeScript
- TailwindCSS

AI

- OpenAI
- PyMuPDF
- FAISS
- RAG
